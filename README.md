# 내 재정 — 개인 재정 PWA

예산(줄어드는 막대) → 저축(차오르는 막대) → 투자(불어나는 선)의 흐름을 한 화면에서 보는 개인용 웹앱.
서버 없이 모든 데이터는 기기의 IndexedDB에만 저장된다.

## 실행

빌드 과정이 없다. 정적 파일을 그대로 올리면 된다.

```sh
python3 -m http.server 8000   # http://localhost:8000
npm test                      # 파서·정산·투자 계산 단위 테스트 (Node 18+)
```

**GitHub Pages 배포**: 저장소 Settings → Pages → Branch에서 이 브랜치(또는 병합한 main)의 `/ (root)` 선택.
폰에서 주소를 연 뒤 Safari "홈 화면에 추가" / Chrome "앱 설치". 서비스 워커는 HTTPS(또는 localhost)에서만 동작한다.

파일을 고친 뒤에는 `sw.js`의 `VERSION`을 올려야 설치된 앱이 새 파일을 받는다.

## 구조

| 파일 | 역할 |
|---|---|
| `index.html`, `style.css` | 화면 (모바일 380px 기준) |
| `js/app.js` | 화면 그리기, 입력 시트, 팝업, 설정·백업 |
| `js/parse.js` | 한 줄 입력 파서 (규칙 기반, 외부 서버 없음) |
| `js/settle.js` | 월말 정산 계산 (순수 함수) |
| `js/ledger.js` | 월 예산 생성, 미정산 달 처리, 잔액 |
| `js/invest.js` | 시장 구분(국내/미국), 원화 환산 원금·평가액 시계열 |
| `js/prices.js` | 시세 따라잡기 — 국내: 금융위원회_주식시세정보, 미국·환율: Alpha Vantage |
| `js/db.js` | Dexie 스키마, 백업 내보내기/가져오기 |
| `vendor/` | Chart.js 4.4.4, Dexie 4.0.8 (오프라인 동작을 위해 저장소에 포함) |

## 설계 문서와 다르게, 또는 구체화한 부분

- **화면 배치**: 예산·저축·투자를 한 홈 화면에 위→아래로 배치해 흐름이 한눈에 보이게 했다. 내역·설정은 하단 탭.
- **입력 시트**: 금액을 먼저 넣고 항목 칩을 탭하면 그 자리에서 저장된다(+ 버튼 → 금액 → 항목 = 터치 2번). 자주 쓴 금액 버튼은 탭하면 바로 저장.
- **한 줄 입력의 항목 우선순위**: 이름 일치 → 이름 앞부분 → 별칭 일치 → 별칭 앞부분. 같은 단계면 앞쪽 단어. 그래서 `교 1500 버스`는 교통비·메모 "버스"로 저장된다.
- **정산**: 앱을 몇 달 만에 열어도 정산 안 된 달을 오래된 순서로 하나씩 처리한다. 감액이 기본 예산보다 크면 그 달 예산은 0원.
- **월말 예고 팝업**: 마지막 날 하루에 한 번만 띄운다.
- **저축 한도 초과 팝업**: 앱을 열 때마다, 그리고 5분 넘게 다른 앱에 있다가 돌아올 때도 다시 확인한다.
- **미국 주식**: 종목코드가 6자리 숫자면 국내, 영문 티커면 미국으로 자동 구분. 미국 종목은 매수 단가(달러)와 매수 시 환율을 입력하고, 환율 칸은 저장된 환율이 있으면 매수일 기준으로 미리 채운다. 평가액은 그날 종가 × 그날 환율(없으면 가장 최근 값, 그것도 없으면 매수 시 환율).
- **Alpha Vantage 호출 절약**: 앱을 열 때 미국 종목·환율은 하루 한 번만, 호출 사이 12초 간격으로 뒤에서 받는다. 한도 초과 응답이 오면 남은 호출을 멈춘다. 무료 키는 최근 100거래일만 주므로 그보다 오래된 날짜의 점은 매수 단가로 평가된다.
- **주식 외 자산**: 투자 카드의 '+ 자산 추가'에서 주식·현금·유동자산·부동산·기타를 고른다. 주식 외 자산은 1원 = 1단위로 넣고(입금) 빼며(출금, 매도 기록과 같은 방식), '가치 갱신'은 그날의 단위 가격(평가액 ÷ 남은 단위)을 시세처럼 저장한다. 가치 갱신 뒤 입금은 그때 단위 가격으로 들어가 평가액이 맞게 유지된다. 종목별 꺾은선은 주식만 그린다.
- **투자 이동**: 종목 등록 화면의 "저축에서 차감할 금액"으로 기록한다. 종목코드 없이 금액만 넣으면 "직접 평가 자산"(수량 1 × 금액)으로 등록된다.
- **평가액 수동 입력**: 입력한 날은 그 값을 쓰고, 이후 시세가 없는 날은 그 값에 새로 늘어난 원금만 더해 이어 그린다.
- **백업**: 시세 API 키(금융위·Alpha Vantage)는 백업 파일에 넣지 않는다. 가져오기 해도 기기에 있던 키는 유지된다.
- **항목 삭제**: 지난 기록 보존을 위해 숨김 처리하고, 이번 달 예산·정산에서만 뺀다.

## 확인하지 못한 것

개발 환경에서 `apis.data.go.kr`, `www.alphavantage.co`에 접속할 수 없어 실제 응답과 CORS 허용 여부를 확인하지 못했다.
아래 형식을 가정하고, 그 형식의 가짜 응답으로 브라우저 테스트만 했다. 키를 넣은 뒤 설정의 "지금 시세 받아오기"로 확인할 것.

- 금융위원회_주식시세정보 `getStockPriceInfo`: 요청 `serviceKey`, `resultType=json`, `likeSrtnCd`, `beginBasDt`, `endBasDt` / 응답 `response.body.items.item[]`의 `basDt`, `srtnCd`, `itmsNm`, `clpr`
- Alpha Vantage `TIME_SERIES_DAILY`(`outputsize=compact`): 응답 `"Time Series (Daily)"` → 날짜별 `"4. close"`
- Alpha Vantage `FX_DAILY`(`from_symbol=USD`, `to_symbol=KRW`): 응답 `"Time Series FX (Daily)"` → 날짜별 `"4. close"`
- 한도 초과·키 오류는 `Note` 또는 `Information`, 잘못된 티커는 `Error Message`로 온다고 가정

막히면 오류 문구가 표시되고, "평가액 직접 입력"으로 대체한다.
